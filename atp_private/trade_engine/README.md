# atp_private.trade_engine — Trade's engine, copied as is

Source: repository `abhishekwasu-hue/Trade`, tag `engine-snapshot-v1`, commit `79feb62d989383cefd14fe7d9c92fd10e9362ce5` (owner order M65: the signal engine, chart reader, price
action, entry models and the Vision method move to ATP as is). Generated by `tools/trade_sync/export_to_atp_private.sh engine-snapshot-v1` — never
edit this folder by hand; a re-sync for a new tag replaces it as a whole.

- Code: 113 modules at their original paths under `atp_private/trade_engine/`, unmodified except the import paths
  (`tools/trade_sync/atp_import_rewrite.py`: `import decision3` ⇒ `import atp_private.trade_engine.decision3 as decision3`, …).
- Tests: 57 files under `tests/` (the Trade tests whose imports stay inside this set). Run: `python -m pytest atp_private/trade_engine/tests`
  from the repository root. Tests that need the private trade-data skip without it.
- Package data: 3 files (e.g. `decision3/data/*.json`). KB / method / Method Pack: 17 files under `docs/knowledge/` (the
  same relative path the code reads); the Method Pack builder is `scripts/build_method_pack.py`.
- Not here: market data, parity fixtures (private fixtures store on the host, `parity/engine-snapshot-v1/` in trade-data), secrets, VPS paths.
- ATP-GENERIC modules (Telegram, PAPER fills, exits, approvals, brokers, storage, config) are NOT copied: ATP has its own. A copied module
  that imports one of them at call time needs ATP's adapter when that path is ported (the list: Trade `docs/reader/EXPORT_MANIFEST.md`).
- PAPER only; LIVE untouched; the method code never goes into ATP's public repository.
